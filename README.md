# NATO Alphabet Converter 🧳🔤

A fun Python project that converts any given word or phrase into the corresponding NATO phonetic alphabet. 🇺🇳

## Description 📜

This program takes an input string, and for each letter, it outputs the corresponding NATO phonetic alphabet code word. It ignores spaces and only converts the alphabetic characters.

### Example 📝
For the word **"hello"**, the output would be:
- H -> Hotel  
- E -> Echo  
- L -> Lima  
- L -> Lima  
- O -> Oscar 

## Features 🌟

- Converts letters in a string into the NATO phonetic alphabet
- Handles both uppercase and lowercase inputs
- Ignores spaces in the input 

# Built With 🛠️
- **Python 3**

# How It Works 🧩
1. The user inputs a word or phrase when prompted. 🗣
2. The program loops through each letter in the input and looks up the corresponding NATO phonetic alphabet code word. 
3. The NATO phonetic alphabet is printed for each letter of the input.
